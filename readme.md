# Castleland Management Website

This is a basic static website for Castleland Management, designed to be used in advertisements both in newspapers and online.

## Features

- Responsive design that works on desktop and mobile devices
- Current auctions section with links to Proxibid catalogs
- About Us section with company information
- Contact form for potential clients
- Professional and clean design

## Files

- `index.html` - The main HTML file for the website
- `styles.css` - CSS styles for the website
- `castleland.png` - Logo image used for branding and favicon
- `favicon.ico` - Favicon for the website (created from castleland.png)
- `placeholder.jpg` - Placeholder image for auctions

## How to Use

1. To view the website locally, simply open the `index.html` file in any web browser.
2. To deploy the website online, upload all files to your web hosting service.

## Customization

You can customize the website by:

1. Updating the contact information in the Contact Us section
2. Adding or removing auction listings in the Current Auctions section
3. Modifying the About Us content to better reflect your company
4. Changing colors and styles in the `styles.css` file
